RaceFlow Voice — clips opcionais (v0.15.1)

Como funciona:
- Sem arquivos aqui, o app usa beep (rs_beep.wav) + mensagem. Nada quebra.
- Para voz falada, coloque .mp3 / .wav / .ogg nestas pastas:
    sfx/voice/LIMITS/   -> advertencia de track limits
    sfx/voice/PIT/      -> excesso nos boxes
    sfx/voice/CAUTION/  -> caution / bandeira amarela
    sfx/voice/PENALTY/  -> punicao (cumprir no box)
- Um arquivo por pasta ja basta (sorteio quando houver varios).
- Volume/velocidade/categorias em HUD & Dados > Telemetria & Voz.

Formato: prefira mp3/wav/ogg (o CSP/FMOD nao decodifica m4a/aac).
